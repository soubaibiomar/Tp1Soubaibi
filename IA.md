# Utilisation de l'IA pendant le TP1

**Problème rencontré :**

Au début du TP1, j'ai voulu essayer d'utiliser Ollama en local à la place de Gemini. J'ai rencontré des difficultés avec le format JSON des requêtes et des réponses, qui n'était pas le même.

**Pourquoi j'ai utilisé l'IA :**

J'ai d'abord essayé de comprendre comment adapter le code, mais je ne savais pas exactement quelles modifications faire. J'ai donc demandé de l'aide à ChatGPT.

**Prompt utilisé :**

« Comment intégrer Ollama en local dans mon TP1 et adapter le format JSON des requêtes et des réponses ? »

**Réponse de l'IA :**

ChatGPT m'a expliqué qu'il fallait adapter la structure JSON utilisée pour communiquer avec le modèle, notamment la manière d'envoyer les messages et de récupérer les réponses.

**Ce que j'ai appris :**

J'ai compris que les API des modèles d'IA n'utilisent pas forcément le même format JSON et qu'il faut adapter le code en fonction de l'API choisie. Cet essai m'a aussi aidé à mieux comprendre comment mon application Java communique avec un modèle d'IA.
